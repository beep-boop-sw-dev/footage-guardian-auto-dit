Footage Guardian

Installing it. This is setup only — Stuart will walk you through using it.

You do all of this in Terminal, once. About 40 minutes, most of it waiting. Stuart is on the other end of the phone if any step looks wrong — send him what the screen says rather than guessing.

Opening Terminal

Press Cmd + Space, type Terminal, press Enter. A window opens with a blinking cursor.

You paste a line in, press Enter, wait for the cursor to come back, then do the next one.

None of this can harm your footage

Nothing in this setup touches a camera, a card, or a drive. It only installs software.

Step 1Install Homebrew

Homebrew is the thing that installs the other things.

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
It asks for your Mac password

That is macOS asking, not us. Typing shows nothing on screen — no dots, no stars. That is normal. Type it and press Enter.

It then prints a lot and takes a few minutes.

Check it worked

brew --version

You should see a version number.

If instead you get command not found: brew, Homebrew did install — it just has not told Terminal where it is. That is normal on this Mac, and it is the most common snag in this whole setup. Paste these three, one at a time:

echo >> ~/.zprofile echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile eval "$(/opt/homebrew/bin/brew shellenv)"

Then try brew --version again. You only ever do this once.

Step 2Get the app

One line. No account, no sign-in.

cd ~/Desktop git clone https://github.com/beep-boop-sw-dev/footage-guardian-auto-dit.git "Footage Guardian"

That puts a folder called Footage Guardian on your Desktop. That is the app.

Step 3Install rclone

This is what talks to Google Drive.

brew install rclone

Check it worked

rclone version

You should see a version number.

Step 4Connect Google Drive

rclone config

This one asks a lot of questions. Answer in this order. Anything not listed here, just press Enter to take the default.

n (new remote) gdrive (name it exactly this — lowercase) drive (the storage type — or type the number shown next to “Google Drive”) [Enter] (client_id — leave blank) [Enter] (client_secret — leave blank) 1 (scope: full access) [Enter] (root_folder_id — leave blank) [Enter] (service_account_file — leave blank) n (edit advanced config? no) y (use web browser to authenticate? yes)

Your browser opens. Sign in as the shared Google account Stuart gave you — not your own personal one — and click Allow. Back in Terminal:

n (configure as a Shared Drive? no) y (yes, this is OK) q (quit config)

Check it worked

rclone lsd gdrive:

It should list your Drive folders, including the team drive Stuart named for you. If you see a sign-in error, run:

rclone config reconnect gdrive:

Step 5Open it once

Open the Footage Guardian folder on your Desktop and double-click:

Footage Guardian Auto DIT.command
If macOS refuses to open it

Right-click the file, choose Open, then click Open in the box that appears. You only need to do that once.

That is setup done

A window opens with four tabs along the top. If you got that far, it worked.

Leave it there — Stuart will take you through the Drives tab and the rest on the phone.

Getting updates later

When Stuart tells you there is a fix, close the app, then paste:

cd ~/Desktop/"Footage Guardian" git pull

That is the whole thing. A second or two, and a short list of what changed. Open the app again afterwards.

An update cannot lose your work

Your settings and your records are not in that folder — they live in your Library folder. So an update never touches which drives you chose, or what has already been copied and verified.

If it mentions local changes being overwritten

Do not force it. Send Stuart the message.

If a step goes wrong

Nothing here can harm your footage. Starting a step over is always safe.

command not found: brew

Homebrew is installed but not on the path yet. Check it is there with ls /opt/homebrew/bin/brew. If that prints a path, run the three lines at the end of Step 1. If it says no such file, Step 1 did not finish — run it again.

command not found: git

Step 1 installs this alongside Homebrew. If it is missing, run xcode-select --install, click through, then try Step 2 again.

The password does nothing when I type it

That is correct and deliberate. Type it anyway and press Enter.

The browser sign-in did not come back

Close the browser tab and run the command again. Nothing is broken by starting a step over.

Anything else

Take a photo of the Terminal window, or copy the text, and send it to Stuart. The exact wording is what tells him what happened.
